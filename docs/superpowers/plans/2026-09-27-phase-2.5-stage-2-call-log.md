# Phase 2.5 Stage 2 — The AI Call Log on Self-Hosted Langfuse: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record every chat-model call's provider, model, feature, timing, token counts and outcome in a self-hosted Langfuse — and nothing else: never a prompt, never a completion, never a user id.

**Architecture:** A small LangChain callback handler of our own, `CallRecorder`, is attached once in `build_chat_model`'s constructor `callbacks=`. It builds a content-free `CallRecord` from the callback lifecycle (start, end with usage, error class) and hands it to a `CallSink`; the Langfuse sink turns each record into one generation observation via the SDK's native API, in a trace whose id is derived from our own id (the assistant message for a chat turn, the change set for a generation run). Every call site passes `config=call_config(CallFeature.X)`; the graph and the generators pass the trace seed, project id and retry attempt once, as inherited metadata. Langfuse runs as five containers behind a `langfuse` Compose profile plus a `langfuse` database on the existing Postgres, with its phone-home disabled.

**Tech Stack:** `langfuse` Python SDK v4 (OpenTelemetry-based), LangChain callbacks (`langchain-core` 1.6), LangGraph 1.2, FastAPI, pytest; Docker Compose.

**Spec:** `docs/superpowers/specs/2026-09-27-phase-2.5-measurement-design.md` §4, §5.4, §6 (Stage 2 rows). **Spec §4 is amended by the research below; the amendments are listed under "Deviations from spec §4" and must be applied to the spec file (uncommitted) in Task 7.**

Research notes this plan relies on (verified 2026-09-27, sources in the session scratchpad `langfuse-research.md`):
- The SDK is **v4** (`langfuse>=4,<5`, latest 4.15.x), an OTel rewrite. `from langfuse.langchain import CallbackHandler` exists, but the plan does **not** use it (see deviation 1).
- `LANGFUSE_BASE_URL` is the current host variable (`LANGFUSE_HOST` is legacy).
- Deterministic trace ids: `create_trace_id(seed=...)`.
- Self-hosted Langfuse **phones home by default**: `TELEMETRY_ENABLED=false` on web and worker, and `CHECKPOINT_DISABLE=1` on web (the Prisma CLI in the web image calls `checkpoint.prisma.io`). Image pulls from `docker.langfuse.com` are a third egress path, handled by operators mirroring images.
- Automated data retention is **Enterprise-only**. On OSS the lever is a ClickHouse TTL.
- Official sizing for the full stack is **4 cores / 16 GiB**, not the 4 GB the spec states.
- The trace URL shape is `{base}/project/{projectId}/traces/{traceId}`.

## Deviations from spec §4 (rulings, to be written into the spec in Task 7)

1. **Our own recorder, not Langfuse's `CallbackHandler`.** In v4 the stock handler writes span attributes directly. The content mask that covers it (`mask_otel_spans`) cannot touch span *events*, and a call's exception is recorded as an event. "Always masked" would therefore depend on a hook that cannot see every path. A recorder that never reads the prompt or completion makes the guarantee structural instead: `CallRecord` has no field that could hold content. It is still attached once, in the factory (spec §0.1 decision 9 holds).
2. **The error's class, never its message.** Spec §4.5 allowed "the scrubbed message". Provider error text can echo request content, and `scrub` removes known secrets, not content. So `CallRecord.error_class` is `type(error).__name__` only.
3. **Ask-answer feedback gets no trace link.** The Stage 1 decision made admins see only the *day* of a vote. A Langfuse trace carries second-precision times, so linking an Ask-answer vote to its trace would undo that decision. `traceUrl` is set only for change-set targets and for checklist/mock-data chat replies (shared documents), and is always `null` for `message` targets.
4. **Sizing and egress** as in the research notes above. Retention is a documented ClickHouse TTL; there is no AskRepo setting for it.

## Global Constraints

- Nothing that could hold a prompt, a completion, retrieved code, a question, or a user id may be passed to the Langfuse SDK. `CallRecord` is the only thing the sink sees.
- `CallRecord` fields, exactly: `feature, provider, model, started_at, ended_at, duration_ms, outcome ("success"|"error"), error_class, input_tokens, output_tokens, trace_seed, project_id, attempt, prompt_version`.
- `CallFeature` values, exactly: `classify, grade, answer, history_answer, propose_checklist, propose_mock_data, map, reduce, generate_mock_data, capability_probe, untagged`.
- Metadata keys on `RunnableConfig`, exactly: `askrepo_feature`, `askrepo_trace_seed`, `askrepo_project_id`, `askrepo_attempt`.
- Tracing never fails a model call. Recorder and sink errors are caught and logged at `WARNING`.
- `LANGFUSE_ENABLED` defaults to `false`. When it is false, the `langfuse` package is never imported and nothing is constructed.
- `build_chat_model` still returns the raw provider class (`ChatOllama`/`ChatOpenAI`/`ChatAnthropic`); `tests/test_chat_model.py`'s `isinstance` checks must keep passing.
- No `# type: ignore`/`# noqa` without a reason on the line. `make check` green at the end.
- **Do not commit** `docs/superpowers/specs/*` or `docs/superpowers/plans/*` (owner's instruction). Stage files explicitly.
- Backend commands from `backend/`, `uv run …`. Never start Ollama. `make infra` datastores are assumed running.

```python
"""Deterministic Langfuse trace ids, derived from our own ids.

A chat turn's trace is seeded with its assistant message id and a generation run's with
its change set id, so a feedback row can link to its trace without storing a trace id
anywhere. The derivation must equal the SDK's `create_trace_id(seed=...)`, and
`tests/test_trace_ids.py` pins that.
"""

import hashlib


def trace_id_for(seed: str) -> str:
    """The Langfuse trace id for `seed`: 32 lowercase hex characters."""
    return hashlib.sha256(seed.encode("utf-8")).digest()[:16].hex()


def trace_url(*, ui_url: str, project_id: str, seed: str) -> str:
    """A browser link to the trace seeded by `seed`."""
    return f"{ui_url.rstrip('/')}/project/{project_id}/traces/{trace_id_for(seed)}"
```

If Step 2 found a different derivation (hex digest sliced to 32, a different hash, a namespace prefix), change `trace_id_for`'s body to match it exactly. The SDK-equality test is the arbiter.

```python
    message = AIMessage(
        content=SECRET_ANSWER,

    project = uuid.uuid4()

    await _model(sink).ainvoke(

    assert call.trace_seed == "cs-1" and call.project_id == project and call.attempt == 2
    assert call.duration_ms >= 0
    assert len(call.prompt_version) == 12

    sink = ListSink()
```

```python
"""Which feature made a model call, and the scope it ran in.

Every chat-model call passes `config=call_config(CallFeature.X)`. The graph and the
generators pass the trace seed, project id and retry attempt once, and LangChain's
inherited metadata carries them to every call beneath. Metadata, not a context
variable: a chat turn's events are pulled through an async generator whose `anext`
may run in a fresh task, so a context variable set there could not be reset safely.
"""

import uuid
from enum import StrEnum

from langchain_core.runnables import RunnableConfig

FEATURE_KEY = "askrepo_feature"
TRACE_SEED_KEY = "askrepo_trace_seed"
PROJECT_KEY = "askrepo_project_id"
ATTEMPT_KEY = "askrepo_attempt"


class CallFeature(StrEnum):
    CLASSIFY = "classify"
    GRADE = "grade"
    ANSWER = "answer"
    HISTORY_ANSWER = "history_answer"
    PROPOSE_CHECKLIST = "propose_checklist"
    PROPOSE_MOCK_DATA = "propose_mock_data"
    MAP = "map"
    REDUCE = "reduce"
    GENERATE_MOCK_DATA = "generate_mock_data"
    CAPABILITY_PROBE = "capability_probe"
    UNTAGGED = "untagged"


def _scope(
    *, trace_seed: str | None, project_id: uuid.UUID | None, attempt: int | None
) -> dict[str, object]:
    metadata: dict[str, object] = {}
    if trace_seed is not None:
        metadata[TRACE_SEED_KEY] = trace_seed
    if project_id is not None:
        metadata[PROJECT_KEY] = str(project_id)
    if attempt is not None:
        metadata[ATTEMPT_KEY] = attempt
    return metadata


def scope_config(
    *, trace_seed: str | None, project_id: uuid.UUID | None, attempt: int | None = None
) -> RunnableConfig:
    """The scope a whole graph run or generation job shares, as inherited metadata."""
    return {"metadata": _scope(trace_seed=trace_seed, project_id=project_id, attempt=attempt)}


def call_config(
    feature: CallFeature,
    *,
    trace_seed: str | None = None,
    project_id: uuid.UUID | None = None,
    attempt: int | None = None,
) -> RunnableConfig:
    """One call's config: its feature, plus scope for a call that has no parent run."""
    metadata = {FEATURE_KEY: feature.value}
    metadata.update(_scope(trace_seed=trace_seed, project_id=project_id, attempt=attempt))
    return {"metadata": metadata}
```

```python
"""The one thing the call log ever sees about a model call.

**No field can hold content.** No prompt, no completion, no question, no message, no
user id — a new field here is a change to `.claude/rules/call-log.md` first, and
`tests/test_call_recorder.py` pins the field set.

import uuid

from datetime import datetime
from typing import Literal, Protocol


@dataclass(frozen=True, slots=True)
class CallRecord:
    feature: str
    provider: str
    model: str
    started_at: datetime
    ended_at: datetime
    duration_ms: int
    outcome: Literal["success", "error"]

    input_tokens: int | None
    output_tokens: int | None
    trace_seed: str | None
    project_id: uuid.UUID | None
    attempt: int | None
    prompt_version: str


class CallSink(Protocol):
```

`recorder.py`:

```python
"""A LangChain callback that records what a model call cost, never what it said.

Attached once, in `build_chat_model`'s `callbacks=`, so every call is recorded by
construction. It reads timing, usage and the error's class from the callback lifecycle
and ignores the `messages` argument entirely: content never enters this module.
Recording can never fail a call — every sink error is logged and swallowed.
"""

import logging
import time
import uuid
from dataclasses import dataclass
from datetime import UTC, datetime
from typing import Any

from langchain_core.callbacks import AsyncCallbackHandler
from langchain_core.outputs import ChatGeneration, LLMResult

from app.observability.features import (
    ATTEMPT_KEY,
    FEATURE_KEY,
    PROJECT_KEY,
    TRACE_SEED_KEY,
    CallFeature,
)
from app.observability.record import CallRecord, CallSink
from app.rag.prompt_version import PROMPT_VERSION

logger = logging.getLogger(__name__)

# A run whose end never arrives (a cancelled stream LangChain did not report) must not
# grow the table forever.
_MAX_OPEN = 1024


@dataclass(frozen=True, slots=True)
class _Open:
    started_at: datetime
    started_mono: float
    feature: str
    trace_seed: str | None
    project_id: uuid.UUID | None
    attempt: int | None


def _uuid_or_none(value: object) -> uuid.UUID | None:
    try:
        return uuid.UUID(str(value)) if value is not None else None
    except ValueError:
        return None


def _usage(response: LLMResult) -> tuple[int | None, int | None]:
    for generations in response.generations:
        for generation in generations:
            if isinstance(generation, ChatGeneration):
                usage = getattr(generation.message, "usage_metadata", None)
                if usage:
                    return usage.get("input_tokens"), usage.get("output_tokens")
    token_usage = (response.llm_output or {}).get("token_usage") or {}
    return token_usage.get("prompt_tokens"), token_usage.get("completion_tokens")


class CallRecorder(AsyncCallbackHandler):
    raise_error = False

    def __init__(self, sink: CallSink, *, provider: str, model: str) -> None:
        self._sink = sink
        self._provider = provider
        self._model = model
        self._open: dict[uuid.UUID, _Open] = {}

    async def on_chat_model_start(
        self,
        serialized: dict[str, Any],
        messages: list[list[Any]],
        *,
        run_id: uuid.UUID,
        metadata: dict[str, Any] | None = None,
        **kwargs: Any,
    ) -> None:
        if len(self._open) >= _MAX_OPEN:
            self._open.clear()
        meta = metadata or {}
        attempt = meta.get(ATTEMPT_KEY)
        self._open[run_id] = _Open(
            started_at=datetime.now(UTC),
            started_mono=time.monotonic(),
            feature=str(meta.get(FEATURE_KEY, CallFeature.UNTAGGED.value)),
            trace_seed=str(meta[TRACE_SEED_KEY]) if meta.get(TRACE_SEED_KEY) else None,
            project_id=_uuid_or_none(meta.get(PROJECT_KEY)),
            attempt=int(attempt) if isinstance(attempt, int) else None,
        )

    async def on_llm_end(self, response: LLMResult, *, run_id: uuid.UUID, **kwargs: Any) -> None:
        opened = self._open.pop(run_id, None)
        if opened is None:
            return
        input_tokens, output_tokens = _usage(response)
        self._emit(opened, outcome="success", error_class=None,
                   input_tokens=input_tokens, output_tokens=output_tokens)

    async def on_llm_error(
        self, error: BaseException, *, run_id: uuid.UUID, **kwargs: Any
    ) -> None:
        opened = self._open.pop(run_id, None)
        if opened is None:
            return
        self._emit(opened, outcome="error", error_class=type(error).__name__,
                   input_tokens=None, output_tokens=None)

    def _emit(
        self,
        opened: _Open,
        *,
        outcome: str,
        error_class: str | None,
        input_tokens: int | None,
        output_tokens: int | None,
    ) -> None:
        try:
            self._sink.record(
                CallRecord(
                    feature=opened.feature,
                    provider=self._provider,
                    model=self._model,
                    started_at=opened.started_at,
                    ended_at=datetime.now(UTC),
                    duration_ms=int((time.monotonic() - opened.started_mono) * 1000),
                    outcome="error" if outcome == "error" else "success",
                    error_class=error_class,
                    input_tokens=input_tokens,
                    output_tokens=output_tokens,
                    trace_seed=opened.trace_seed,
                    project_id=opened.project_id,
                    attempt=opened.attempt,
                    prompt_version=PROMPT_VERSION,
                )
            )
        except Exception:
            logger.warning("the call log could not record a %s call", opened.feature, exc_info=True)
```

```python
"""Sends call records to a self-hosted Langfuse — metadata only, never content.

`langfuse` is imported only inside `build_call_log` when the call log is enabled, like
the provider imports in `app/rag/chat.py`: an instance with it off never loads it.
"""

import logging
from dataclasses import dataclass, field
from typing import Any

from langchain_core.callbacks import BaseCallbackHandler

from app.config import Settings
from app.observability.record import CallRecord
from app.observability.recorder import CallRecorder
from app.observability.trace_ids import trace_id_for

logger = logging.getLogger(__name__)


class LangfuseSink:
    """One Langfuse generation observation per call record."""

    def __init__(self, client: Any) -> None:
        self._client = client

    def record(self, call: CallRecord) -> None:
        usage = {
            key: value
            for key, value in (("input", call.input_tokens), ("output", call.output_tokens))
            if value is not None
        }
        kwargs: dict[str, Any] = {
            "name": call.feature,
            "as_type": "generation",
            "model": call.model,
            "start_time": call.started_at,
            "metadata": {
                "provider": call.provider,
                "feature": call.feature,
                "project_id": str(call.project_id) if call.project_id else None,
                "attempt": call.attempt,
                "prompt_version": call.prompt_version,
                "duration_ms": call.duration_ms,
                "outcome": call.outcome,
            },
        }
        if call.trace_seed:
            kwargs["trace_context"] = {"trace_id": trace_id_for(call.trace_seed)}
        if usage:
            kwargs["usage_details"] = usage
        if call.outcome == "error":
            kwargs["level"] = "ERROR"
            kwargs["status_message"] = call.error_class
        observation = self._client.start_observation(**kwargs)
        observation.end(end_time=call.ended_at)


@dataclass
class CallLog:
    """The process's call log: callbacks to attach, and a shutdown that flushes."""

    callbacks: list[BaseCallbackHandler] = field(default_factory=list)
    _client: Any = None

    def shutdown(self) -> None:
        if self._client is None:
            return
        try:
            self._client.shutdown()
        except Exception:
            logger.warning("the call log failed to flush on shutdown", exc_info=True)


def build_call_log(settings: Settings) -> CallLog:
    """A recorder wired to Langfuse when enabled; an empty call log otherwise."""
    if not settings.langfuse_enabled:
        return CallLog()
    from langfuse import Langfuse

    client = Langfuse(
        public_key=settings.langfuse_public_key,
        secret_key=settings.langfuse_secret_key,
        base_url=settings.langfuse_base_url,
        environment=settings.app_env,
    )
    recorder = CallRecorder(
        LangfuseSink(client), provider=settings.chat_provider, model=settings.chat_model
    )
    return CallLog(callbacks=[recorder], _client=client)
```

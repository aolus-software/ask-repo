# Phase 2.7 PR B — Eval Sets in Other Languages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An English eval set can be translated, pair for pair, into any of the six other shipped languages; the translated set runs through today's unchanged answer graph and is compared with its English source question by question. Together these give the per-language baseline that PR C's answer change is measured against.

**Architecture:** `eval_sets` gains `language` and `source_set_id`, and `eval_pairs` gains `source_pair_id` and `exclusion_reason`. `POST /projects/{id}/eval-sets` accepts a second body shape, `{sourceSetId, language}`, and writes a `generating` set that copies its source's scope. The existing generation job, lease, sweep, live events and notifications are reused. Only the body of `EvalSetGenerator.run` branches: with a `source_set_id` it translates each source pair with one tagged model call (`CallFeature.EVAL_TRANSLATE`) instead of scrolling the index. A mechanical check then requires every backticked span and every path-shaped token to survive the translation. A pair that fails the check twice is written excluded, with `exclusion_reason = 'translation_unfaithful'`. The judge prompt gains one sentence so that a reply's language alone is never a reason to mark it down. The frontend gets a Translate dialog, language display, and a "compare with source" view that pairs runs through `sourcePairId`.

**Tech Stack:** FastAPI, SQLAlchemy 2 (async), Alembic, Pydantic v2, LangChain structured output, pytest (backend); Next.js 16, React 19, `next-intl`, TanStack Query, Vitest (frontend).

**Spec:** `docs/superpowers/specs/2026-10-17-phase-2.7-multi-language-design.md` — §0.1 decisions 5, 7 and 9; §1.1 (`LANGUAGE_NAMES` only); §1.2 (the `eval_sets.language` row only); §3 in full; §6 (the "Translated eval set" row); §7 (the PR B bullets); §8 "PR B". `projects.content_language`, `PATCH /projects/{id}`, reply-language prompts, refusals and email belong to PR C and are **not** in this plan.

## Global Constraints

- Languages, exactly: `en`, `id`, `ja`, `ms`, `zh-HK`, `zh-TW`, `ko` (`app.core.language.Language`). Values are a wire contract: add members, never rename them.
- `eval_sets.language` is `String(8)`, not null, default `'en'`. `eval_pairs.exclusion_reason` is `String(32)`, nullable; `'translation_unfaithful'` is its only value in this phase, and a hand exclusion leaves it `NULL`.
- A translated set is derived from a `ready` English set with `source_set_id IS NULL` in the same project. It is never generated natively, and never derived from another translation.
- At most one live (not soft-deleted) translation per `(source_set_id, language)`. A second request gets `409 EVAL_TRANSLATION_EXISTS`, a new `ErrorCode`: add it, never rename it.
- A translated set copies `source_path`, `requested_count`, `mix` and `indexed_generation` from its source. It reads no index of its own.
- Translation is **never** checked for fluency. The prompt and the mechanical check exist to keep identifiers, paths and backticked spans verbatim.
- Every model call passes `config=call_config(CallFeature.X, ...)` (`.claude/rules/call-log.md` rule 3). No question, translation or reference text reaches a log line, an error column or the audit trail: an error is logged by its class name only.
- Nothing feedback-authored reaches a model (`.claude/rules/feedback.md` rule 1). `app/eval/` imports no feedback module.
- Access is unchanged: `eval.run` to request, `eval.read` to read. A set in a project the caller cannot see answers `404`. No new permission. No change to `app/core/access.py`. No new live-event kind.
- Audit: `eval_set.generation.requested` gains the context keys `language` (always) and `sourceSetId` (translations only). It is not a new event name.
- Frontend: every user-visible string comes from `frontend/messages/<locale>/`, all seven locales carry the same keys and ICU placeholders, and the six non-English drafts stay `reviewed: false`. Never use a `dark:` colour utility or a palette utility. Use `render={...}`, never `asChild`.
- Backend: annotate every function, give every public unit a docstring, and keep `ruff` and `mypy` clean (`.claude/rules/clean-code.md`). Only repositories import `select`, `update`, `insert` or `delete` (`.claude/rules/persistence.md`).

## Rulings (decisions the spec left open, made here)

- **R1. One body model, not a union.** `EvalSetCreate` keeps its name and gains optional `sourceSetId` and `language`; a model validator enforces exactly one shape. A Pydantic union would prefix every `422` field key with the member's class name (`EvalSetCreate.name`), which breaks `fields`/`fieldTypes` keying (`app/core/errors.py:_field_name`). The cost is that a cross-field error (for example, a generation body with no `name`) reports under the `request` key rather than `name`. The Generate dialog already requires a name before it submits.
- **R2. An invalid source is `422` with a `fields` map**, keyed `sourceSetId`, with `fieldTypes.sourceSetId = "eval_source_invalid"`. The message is the same whether the id is unknown, in another project, not `ready`, a translation itself, or soft-deleted, so a `422` never reveals that a set exists in a project the caller cannot see. The route already declares `422` as `ValidationErrorBody`, so no new response model is needed.
- **R3. The name is derived:** `"{source name} · {language}"`, with the source name truncated so the whole stays within 120 characters. The body carries no name, matching spec §3.3.
- **R4. Concurrency is serialised on the source set's row lock.** It is the same `EvalSetRepository.lock` that `start_run` and `delete_set` take. A partial unique index on `(source_set_id, language) WHERE deleted_at IS NULL AND source_set_id IS NOT NULL` is the backstop.
- **R5. Every source pair is translated, including ones excluded in the source.** A copied hand exclusion keeps `exclusion_reason = NULL`, so it can be included again later.
- **R6. Unfaithful pair content.** An unfaithful pair stores the *last translation attempt's* text, so a reviewer can see what went wrong. When no attempt returned text, it stores the English question. `reference_answer` is always the English reference.
- **R7. Ready or failed.** A translation is `ready` when at least one pair passed the faithfulness check; otherwise it is `failed` with `NO_FAITHFUL_TRANSLATION_ERROR`. `pair_count` counts every pair written, excluded ones included, as native generation already does.
- **R8. Deleting the source set is allowed.** Its translations stay runnable. "Compare with source" disappears, because the source's runs then answer `404`, and the screen says the source was deleted.
- **R9. The cross-language comparison is computed in the browser**, with the same `compareRuns` the within-set comparison uses, remapping the translated run's pair ids through `sourcePairId`. No backend route is added.
- **R10. The compare view warns on any stamp difference.** It warns when chat model, judge model, answer prompt version or judge prompt version differ, which is what spec §3.6 asks for. Today only the judge model is checked. The existing judge-model warning text is kept, and one new warning covers the other three.

```python
class EvalSetCreate(ApiModel):
    """Ask for a set: generated natively in English, or translated from an English set.

    Generation sends `name`, `count`, `mix` and optionally `sourcePath`; translation sends
    `sourceSetId` and `language` and nothing else (spec §3.3). One model rather than a
    union: a union prefixes every `422` field key with the member's class name, which
    breaks the `fields`/`fieldTypes` keying the frontend translates by.

    `count` is a literal rather than a range: three sizes are what the cost estimate
    and the one-job-at-a-time cap were reasoned about.
    """

    name: str | None = Field(default=None, min_length=1, max_length=NAME_MAX_LENGTH)
    source_path: str | None = Field(default=None, max_length=1024)
    count: Literal[10, 25, 50] | None = None
    mix: EvalMix | None = None
    source_set_id: uuid.UUID | None = None
    language: Language | None = None

    @model_validator(mode="after")
    def _exactly_one_shape(self) -> Self:
        generation = (self.name, self.source_path, self.count, self.mix)
        if self.source_set_id is None:
            if self.language is not None:
                raise ValueError("language is only sent with sourceSetId")
            if self.name is None or self.count is None or self.mix is None:
                raise ValueError("name, count and mix are required")
            return self
        if any(value is not None for value in generation):
            raise ValueError("a translation sends only sourceSetId and language")
        if self.language is None:
            raise ValueError("language is required with sourceSetId")
        if self.language is Language.EN:
            raise ValueError("a translation's language must not be en")
        return self

    @property
    def is_translation(self) -> bool:
        """Whether this body asks for a translation rather than a generation."""
        return self.source_set_id is not None
```

    async def _new_generation(
        self, project: Project, payload: EvalSetCreate, *, actor: AuthenticatedUser
    ) -> EvalSet:
        """A natively generated English set."""
        if payload.name is None or payload.count is None or payload.mix is None:
            raise AssertionError("EvalSetCreate validated a generation body without its fields")
        if payload.source_path:
            await require_path_indexed(self.indexed_paths, project, payload.source_path)
        return await self.sets.add(
            EvalSet(
                id=uuid.uuid4(),
                project_id=project.id,
                name=payload.name.strip(),
                source_path=payload.source_path or None,
                requested_count=payload.count,
                mix=payload.mix.value,
                language=Language.EN.value,
                status=EvalSetStatus.GENERATING.value,
                pair_count=0,
                created_by=actor.id,
            )
        )

    async def _new_translation(
        self, project: Project, payload: EvalSetCreate, *, actor: AuthenticatedUser
    ) -> EvalSet:
        """A set translating a ready English set, pair for pair (spec §3.1-§3.3).

        The source's row lock serialises two requests for the same language, the same
        lock `start_run` and `delete_set` take; the partial unique index is the backstop.
        """
        if payload.source_set_id is None or payload.language is None:
            raise AssertionError("EvalSetCreate validated a translation body without its fields")
        source = await self.sets.lock(payload.source_set_id)
        if (
            source is None
            or source.project_id != project.id
            or source.status != EvalSetStatus.READY.value
            or source.language != Language.EN.value
            or source.source_set_id is not None

        language = payload.language.value
        if await self.sets.live_translation(source.id, language) is not None:
            raise AppError(
                status.HTTP_409_CONFLICT,
                ErrorCode.EVAL_TRANSLATION_EXISTS,
                "This set already has a translation into that language.",
            )
        suffix = f" · {language}"
        return await self.sets.add(
            EvalSet(
                id=uuid.uuid4(),
                project_id=project.id,
                name=source.name[: NAME_MAX_LENGTH - len(suffix)] + suffix,
                source_path=source.source_path,
                requested_count=source.requested_count,
                mix=source.mix,
                language=language,
                source_set_id=source.id,
                indexed_generation=source.indexed_generation,
                status=EvalSetStatus.GENERATING.value,
                pair_count=0,
                created_by=actor.id,
            )
        )

    @staticmethod
    def _source_invalid() -> AppError:
        """One `422` for every unusable source, so it never says which reason applied —
        or whether a set exists in a project the caller cannot see (ruling R2)."""
        message = "The source must be a ready English set in this project."
        return AppError(
            status.HTTP_422_UNPROCESSABLE_ENTITY,
            ErrorCode.VALIDATION_ERROR,
            message,
            extra={
                "fields": {"sourceSetId": message},
                "fieldTypes": {"sourceSetId": "eval_source_invalid"},
            },
        )

```python
"""Translating one eval question, and checking mechanically that it kept its code.

A translated set exists to measure the language, so a translation that renames an
identifier or drops a path would measure the translator instead (spec §3.4). The check
is mechanical, not a second model call: every backticked span and every path-shaped
token in the English question must appear unchanged in the translation.

No question or translation text reaches a log line: a failed attempt is logged by the
error's class alone (`.claude/rules/call-log.md` rule 2).
"""

import logging
import re
from dataclasses import dataclass
from typing import Any

from langchain_core.messages import BaseMessage
from langchain_core.runnables import Runnable

from app.core.language import Language
from app.eval.model_output import TranslatedQuestion
from app.observability.features import CallFeature, call_config
from app.rag.errors import classify_chat_error
from app.rag.grounding import path_tokens
from app.rag.prompts import build_eval_translate_prompt

logger = logging.getLogger(__name__)

# One retry after the first attempt: spec §3.4, "retried once".
ATTEMPTS = 2

_BACKTICKED = re.compile(r"`([^`\n]+)`")


@dataclass(frozen=True, slots=True)
class Translation:
    """The last attempt's text, or `None` if no attempt returned any, and whether it passed."""

    question: str | None
    faithful: bool


def protected_tokens(text: str) -> set[str]:
    """What a translation of `text` must keep verbatim: backticked spans and paths."""
    return set(_BACKTICKED.findall(text)) | set(path_tokens(text))


def is_faithful(source: str, translation: str) -> bool:
    """Whether `translation` is non-empty and contains every protected token of `source`."""
    if not translation.strip():
        return False
    return all(token in translation for token in protected_tokens(source))


async def translate_question(
    model: Runnable[list[BaseMessage], Any],
    *,
    question: str,
    language: Language,
    scope: dict[str, Any],
) -> Translation:
    """Translate one question, retrying once when the result is unusable or unfaithful.

    A classified provider error raises — terminal fails the job, retryable defers it —
    exactly as in `EvalSetGenerator._generate_one`; anything else counts as one failed
    attempt.
    """
    last: str | None = None
    for _ in range(ATTEMPTS):
        try:
            result = await model.ainvoke(
                build_eval_translate_prompt(question=question, language=language),
                config=call_config(CallFeature.EVAL_TRANSLATE, **scope),
            )
        except Exception as error:
            classified = classify_chat_error(error)
            if classified is not None:
                raise classified from error
            logger.warning("an eval question could not be translated: %s", type(error).__name__)
            continue
        if not isinstance(result, TranslatedQuestion):
            continue
        candidate = result.question.strip()
        if candidate:
            last = candidate
        if is_faithful(question, candidate):
            return Translation(question=candidate, faithful=True)
    return Translation(question=last, faithful=False)
```

    async def _translate(self, eval_set: EvalSet, scope: dict[str, Any]) -> list[EvalPair]:
        """One pair per source pair, in source order, with the source's current exclusions.

        An unfaithful pair is written excluded with `translation_unfaithful` and keeps the
        last attempt's text, or the English question when no attempt returned any (ruling
        R6). A copied hand exclusion keeps `exclusion_reason` `NULL`, so it can be
        included again; from here the two sets' exclusions are independent.
        """
        if eval_set.source_set_id is None:
            raise AssertionError("_translate needs a translated set")
        sources = await self.pairs.list_for_set(eval_set.source_set_id, include_excluded=True)
        model = self.chat_model.with_structured_output(TranslatedQuestion)
        language = Language(eval_set.language)

        for source in sources:
            outcome = await translate_question(
                model, question=source.question, language=language, scope=scope
            )

export function TranslateEvalSetDialog({
  projectId,

        error={mutation.error}

  /**
   * Maps the head run's pair ids to the base run's, for comparing a translated set's run
   * with its source's (spec §3.6). Without it both runs are of the same set.

  headToBase?: Map<string, string>;

export function compareRuns(
  base: EvalRunDetail,
  head: EvalRunDetail,
  options: CompareOptions = {},

    if (key) headById.set(key, result);
  }
